# Development Log - Week 18
**Date:** 20–27 July 2026

## Overview

This week marked a major milestone in the project with the successful implementation of the first working A* pathfinding system. Enemy units are now capable of navigating dynamically generated routes around environmental obstacles, moving the project from fixed patrol paths towards autonomous AI behaviour.

Although visually the game has only changed slightly, the underlying engine architecture has taken a significant step forward.

---

## Engine

### A* Pathfinding
- Implemented initial A* pathfinding system.
- Added node generation across a configurable grid.
- Implemented:
  - Start nodes
  - Goal nodes
  - Solid (blocked) nodes
  - Open / Closed node processing
  - Path reconstruction
- Successfully converted node paths into waypoint arrays compatible with the existing movement system.

---

### Node System

Created a dedicated NodeSystem responsible for:

- Grid creation
- Node storage
- Cost calculation
- Automatic path searching
- Path extraction

Initially nodes were manually defined before transitioning to automatic generation.

---

### Environment Integration

Connected the EnvironmentSystem directly into the NodeSystem.

The navigation grid is now generated automatically from level geometry.

Benefits:

- Walls immediately become blocked navigation nodes.
- Navigation automatically reflects map layout.
- Foundation created for future dynamic environments.

---

### Path Simplification

Implemented the first version of path simplification.

Instead of returning every node generated by A*, the system now reduces paths down to only the important turning points.

Example:

Before:

- 40 waypoint nodes

After:

- 7 significant waypoint positions

Benefits:

- Cleaner movement
- Fewer waypoint transitions
- Reduced state updates
- Foundation for future path smoothing

---

## AI

### Dynamic Priority Waypoints

Enemy units can now receive dynamically generated priority destinations.

Successfully stress tested:

- 32 simultaneous enemies
- 50 simultaneous enemies
- 100 simultaneous enemies

Performance remains excellent for typical gameplay numbers.

---

### Vision System

Next step:

- Use the cone for player detection.
